# استمارة تجربة Supabase (Supabase Test Form)

استمارة ويب متجاوبة وخفيفة لإرسال البيانات مباشرة إلى خوادم Supabase عبر واجهة REST الآمنة والمفتاح العام (`Publishable Key`).

---

## 1. إعداد جدول قاعدة البيانات في Supabase

لتمكين الاستمارة من حفظ الرسائل بنجاح، يُرجى تشغيل أمر SQL الآتي في **SQL Editor** داخل لوحة تحكم مشروعك في Supabase:

```sql
-- 1. إنشاء جدول الرسائل
create table public.messages (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  message text not null,
  created_at timestamptz default now() not null
);

-- 2. تفعيل سياسة أمان الصفوف (Row Level Security)
alter table public.messages enable row level security;

-- 3. السماح بالإرسال العام من الاستمارة عبر المفتاح العام
create policy "Allow public inserts" on public.messages
  for insert
  to anon
  with check (true);
```

---

## 2. التقنيات المستخدمة

- **الواجهة:** HTML5 الدلالي، مع مراعاة كاملة لمعايير الوصولية (WCAG 2.1 AA وقارئات الشاشة).
- **التنسيق:** Tailwind CSS عبر شبكة CDN الرسمية.
- **إدارة الحالة:** Alpine.js.
- **قاعدة البيانات:** Supabase REST API (PostgREST).
